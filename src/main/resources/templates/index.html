System Foundation Baseline
  • Runtime: Java 21 LTS
  • Framework: Spring Boot 3.4.3
  • Database: H2 In-Memory (JPA/Hibernate)
  • Build Engine: Apache Maven 3.10.0 Wrapper
  • Test Engine: JUnit 5 & Spring Boot Test

Platform Capabilities & Development Roadmap

Structured 14-week milestone implementation covering application development and DevOps automation.

1. Metadata Submission

Structured entry for 12 paper fields including title, authors, abstract, keywords, publication year, and DOI link.

Sprint: Week 4
2. Public Catalog & Search

Real-time keyword, title, and author search with strict privacy protection (submitter email is never exposed publicly).

Sprint: Week 5
3. Peer-Review State Machine

Role-enforced status lifecycle: SUBMITTED → UNDER_REVIEW → ACCEPTED, REJECTED, or REVISION_REQUESTED.

Sprint: Week 6
4. CI/CD & DevOps Pipeline

Automated Maven builds, JUnit 5 & Selenium E2E testing via Jenkins CI, Docker container packaging, and Ansible playbooks.
